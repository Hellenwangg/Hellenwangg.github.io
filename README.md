# Hellen Wang — UI/UX Portfolio

A simple static site (HTML + CSS), hosted free on GitHub Pages.

## Files

```
index.html       Home page (hero, work, contact)
about.html       About me page
hairsay.html     Hairsay case study
wildsafe.html    Wildsafe case study
drawings.html    Drawings gallery
style.css        All styling (colours, fonts, layout)
script.js        Small helpers (fade-in, image placeholders)
images/          Put all your images here
```

## Image checklist

Download each image from your Notion pages (click image → ••• → Download) and save it with **exactly** this name.
Any missing image shows as a dashed box saying which file to add, so you can check what's left.
